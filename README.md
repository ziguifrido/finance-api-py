# Finance API with FastAPI and yfinance
This is a simple API built with Python and FastAPI to query detailed information about Stocks and Real Estate Investment Funds (REITs) listed on the stock exchange, using the yfinance library.

## Features
* Get data from any ticker through a GET request.
* Returns a complete JSON with the information provided by the .info() function of yfinance.
* Input validation for ticker symbols (`[A-Z0-9.-]`, max 16 chars, normalized with `strip().upper()`).
* Error handling for not found, invalid input, and upstream provider failures.
* Rate limiting: 30 requests per minute per IP to prevent abuse.

## How to Run the Project
You can run the project in two ways: locally with a Python virtual environment or using Docker.

### Method 1: Local Execution

#### 1. Prerequisites

* Python 3.13 installed.

#### 2. Create a Virtual Environment

It is a good practice to create a virtual environment to isolate the project's dependencies.

##### Windows
```bash
    python -m venv .venv
    .venv\Scripts\activate
```

##### macOS / Linux
```bash
    python3 -m venv .venv
    source .venv/bin/activate
```

#### 3. Install Dependencies

With the virtual environment activated, install the necessary libraries from the requirements.txt file.

```bash
    pip install -r requirements.txt
```

#### 4. Start the Server

Use uvicorn to start the API server. The command below will cause the server to restart automatically whenever you save a change to the code.

```bash
    uvicorn main:app --reload
```

> The server will be running at http://127.0.0.1:8000.

### Method 2: Execution with Docker

> **Note**: The Docker container exposes port 8888, not 8000.

1. Ensure the Docker network `app` exists:
```bash
docker network create app
```

2. Build and start the container:
```bash
docker-compose up -d --build
```

3. The server will be running at http://127.0.0.1:8888.

4. To stop the container:
```bash
docker-compose down
```

## Rate Limiting

The API implements rate limiting to prevent abuse: **30 requests per minute per IP**.

When the limit is exceeded, the API returns:
- **Status code**: 429 Too Many Requests
- **Response**:
```json
{
    "message": "Rate limit exceeded",
    "code": 429
}
```

## How to Use the API
After starting the server (by either method), you can access the interactive documentation (Swagger UI) automatically generated by FastAPI to easily test the endpoint.

Access the documentation at: http://127.0.0.1:8000/docs

#### Example Request

To get information about Petrobras (PETR4), make a GET request to the following URL:

http://127.0.0.1:8000/ticker/PETR4.SA

> Important: Remember to add the .SA suffix for assets traded on the São Paulo stock exchange (B3).

### Input Validation

Symbols are accepted only when they match:

- Allowed characters: letters, numbers, dot (`.`), and hyphen (`-`)
- Max length: 16 characters
- Input is normalized with `strip().upper()`

Invalid symbols return:

```json
{
    "message": "Invalid ticker symbol format. Use up to 16 characters from letters, numbers, dot, and hyphen.",
    "code": "INVALID_INPUT"
}
```

### Error Responses

- `404 NOT_FOUND`: ticker not found or no information available
- `503 SERVICE_UNAVAILABLE`: upstream provider/network error while fetching data

### Ticker Examples:

* **Brazilian Stock**: PETR4.SA (Petrobras), MGLU3.SA (Magazine Luiza)
* **International Stock**: AAPL (Apple), GOOGL (Google)
* **Brazilian REIT (FII)**: MXRF11.SA (Maxi Renda), HGLG11.SA (CSHG Logística)
