# Finance API with FastAPI and yfinance
This is a simple API built with Python and FastAPI to query detailed information about Stocks and Real Estate Investment Funds (REITs) listed on the stock exchange, using the yfinance library.

## Features
* Get data from any ticker through a GET request.
* Returns a complete JSON with the information provided by the .info() function of yfinance.
* Error handling for unfound or invalid tickers.

## How to Run the Project
You can run the project in two ways: locally with a Python virtual environment or using Docker.

### Method 1: Local Execution

#### 1. Prerequisites

* Python 3.7+ installed.

#### 2. Create a Virtual Environment

It is a good practice to create a virtual environment to isolate the project's dependencies.

##### Windows
```bash
    python -m venv venv
    venv\Scripts\activate
```

##### macOS / Linux
```bash
    python3 -m venv venv
    source venv/bin/activate
```

#### 3. Install Dependencies

With the virtual environment activated, install the necessary libraries from the requirements.txt file.

```bash
    pip install -r requirements.txt
```

#### 4. Start the Server

Use uvicorn to start the API server. The command below will cause the server to restart automatically whenever you save a change to the code.

```bash
    uvicorn main:app --reload
```

> The server will be running at http://127.0.0.1:8000.

### Method 2: Execution with Docker (Recommended)

This approach containerizes the application, making it more portable and isolated.

#### 1. Prerequisites

Docker and Docker Compose installed.

#### 2. Build and Start the Container

In the project's root directory (where the docker-compose.yml is located), run the following command:

```bash
    docker-compose up -d --build
```

> `up`: Creates and starts the containers.

> `-d`: Runs the containers in "detached" mode (in the background).

> `--build`: Forces the image to be rebuilt from the Dockerfile.

> The server will be running at http://127.0.0.1:8000.

#### 3. To Stop the Container

To stop the application, run:

```bash
    docker-compose down
```

### How to Use the API
After starting the server (by either method), you can access the interactive documentation (Swagger UI) automatically generated by FastAPI to easily test the endpoint.

Access the documentation at: http://127.0.0.1:8000/docs

#### Example Request

To get information about Petrobras (PETR4), make a GET request to the following URL:

http://127.0.0.1:8000/ticker/PETR4.SA

> Important: Remember to add the .SA suffix for assets traded on the São Paulo stock exchange (B3).

### Ticker Examples:

* **Brazilian Stock**: PETR4.SA (Petrobras), MGLU3.SA (Magazine Luiza)
* **International Stock**: AAPL (Apple), GOOGL (Google)
* **Brazilian REIT (FII)**: MXRF11.SA (Maxi Renda), HGLG11.SA (CSHG Logística)
